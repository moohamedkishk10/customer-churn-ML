Data / Dataset
IBM Telco Customer Churn: a sample dataset from IBM describing customers of a fictional telecom company (7,043 customers). Target column: `Churn Value` (1 = left, 0 = stayed).

Source
Kaggle: https://www.kaggle.com/datasets/yeanzc/telco-customer-churn-ibm-dataset

 How to get the data
1. Open the Kaggle link above.
2. Click "Download" and extract the archive.
3. Place the file `Telco_customer_churn.xlsx` in this folder (`data/`).

The training script expects this exact path: `data/Telco_customer_churn.xlsx`.

 Note
The data file is not uploaded to GitHub. It is excluded in `.gitignore` (`data/*.xlsx` and `data/*.csv`).
